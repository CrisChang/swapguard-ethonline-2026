新版已发布到原有 SwapGuard 网站。定位改为：**自动 Swap 的任务级成本与原始约束检查**，而非新增滑点功能或承诺更省钱。这里只记录网站、代码和文案；ETHGlobal 最终提交未代办。

进入 Task workbench，保留默认设置，确认条件后点击 Create replay task，再点击 Run remaining replay，即可看到“授权 → 首笔回滚 → 重试成功 → 最终报告”。也可以逐步操作并导出 JSON。刷新浏览器能恢复已记账费用和待处理回执，不会后台交易。

## 必须保留的区别

**网站闭环是模拟回放，不是自动实盘。** 真实主网只读报价仍是独立面板；没有连接你的钱包或发送主网交易。固定预算是发出前的估算条件，不是链上强制总支出上限。

默认网站回放：0.04 WETH、最低 100.195216 USDC、Gas 预算 3 USDC 等值；授权一次、Swap 尝试两次，构造路径的总 Gas 为 1.743131 USDC 等值。独立本地分叉证明固定 1 gwei，费用为 0.807383 USDC 等值；二者 Gas 路径不同，不能拿来当省费比较。池手续费已经体现在报价中，不能再重复扣。

首轮冻结试验依然保留费用优先方案 28/48 成交、立即执行 34/48 的负面结果。不保证更高成交率，也未证明优于 Uniswap 官方智能路由。

**实时报价仍需独立 RPC：** 后续排查修正了备用节点批量请求超过免费限制的问题，并改为独立单条请求和脱敏日志。云端进一步确认收到上游 429 限流，现在明确返回 503 和重试提示，不拿样例价格代替。232 项单元/API/证据测试通过，但这不等于线上行情已经恢复；需要配置 `ETHEREUM_RPC_URL` 后重新验证。回放不依赖 RPC，其他项目未改。完整历史见 [VALIDATION.md](VALIDATION.md)。

本届 Uniswap 奖项公开规则未要求主网真金白银交易；当前是主网只读行情、模拟网页回放和本地分叉假资金执行，不是公共测试网交易。详见 [网络与参赛边界](NETWORK_REQUIREMENTS.md)。
